# 声学与数值复核（2026-11-10 回滚定稿：FFT 4096 + 相干扩散 LFE send）

## 结论与证据等级

本项目可以合理地称为**基于 HRIR 的耳机双耳渲染器，附带启发式立体声上混、可选的 LFE send 低频增强和可选的安全限幅**，不能称为经校准的 Dolby/DTS 渲染器、通用中性耳机补偿器或听力保护器。

- **数学成立**：线性卷积、14 通道 HeSuVi 映射、BW4 系数、双耳求和、全通幅度为 1、延迟时序、单位换算、自相关 FIR 的非负频响。
- **明确模型下成立**：等权相干参考的相位拟合、指定输入协方差的参考电平估计。
- **工程近似**：相位拟合、固定延迟、预设电平匹配、内容检测、HRIR 重采样。
- **产品偏好**：120 Hz/BW4、2×原生 LFE、balanced/impact send（−6 dB / 0 dB，带 30°/15° 门控）、0.30 输出增益、5 ms/240 样本前瞻。它们不是声学定律。

数值均为数字域，不是耳膜 SPL。没有耳机传递函数、佩戴状态和个体实测，不能证明外化效果、定位准确性、耐听程度或听力安全。

## 1. 双耳渲染和通道映射

对耳 e：

`y_e(t) = Σ_i h_(e,i)(t) * x_i(t)`。

这是固定头部/方向下的线性时不变近似。实际耳机重放还包含 DAC、耳机及耳道耦合的传递函数，HRIR 不等于“已包含当前耳机响应”。头部运动、个体差异、房间、源距离不能从任意通用 14ch 文件自动恢复。

映射与本机 PipeWire 官方 `sink-virtual-surround-7.1-hesuvi.conf` 的 14 个主卷积器逐项一致：左耳索引 `[0,8,6,4,12,2,10]`、右耳 `[1,7,13,5,11,3,9]`，顺序 FL FR FC RL RR SL SR。后半块的交错不能凭直觉改动。

**0-latency 卷积算法不等于整条音频链零延迟**：算法可不增加块延迟，但 IR 自身的起始延迟、群延迟、上混缓冲、对齐延迟和系统调度仍存在。IR 等长本身也不保证各路径相位或到达时间相同。HRTF 常用最小相位+显式 ITD 近似，不意味着可以丢弃 ITD，也不证明所有相位差都不可闻。

## 2. LFE 音色：七对 HRIR 的相干平均（扩散场近似）

默认 `lfe_timbre=diffuse` 是兼容保留的配置名。**当前实现是七对 HRIR 的相干平均**（每耳 `Σ H_c/7`），按中心 HRIR 的 40–80 Hz 平均幅度归一化。这是历史上被称为“扩散场”的相干实现；它**不是**物理扩散场的功率平均 `sqrt((1/14) Σ|H_c|²)`——相干平均会因方向相位相消产生零点，七个水平方向也不足以代表完整球面扩散场。功率平均目标（含最小相位谱分解）曾在 2026-11-10 短暂实现后回滚；如需无零点的方向能量目标，应重新实现而不是引用本文件旧版本。

`lfe_timbre=delta` 仍是无染色单位冲激，`center` 是中心 HRIR 对；三者的对齐全按实际选择的音色响应计算。

## 3. LFE 电平的适用前提

- 2×电压 = `20 log10(2) = 6.0206 dB`，不是 +10 dB，也不是严格 +6.0 dB。
- 扬声器 LFE 的 +10 dB 惯例属于规定的监听校准/频带语境；不能无条件转换为任意耳机路径的数字增益。
- Apple 官方明确：Dolby Renderer 中 LFE 的双耳模式为 Off，仍参与输出，只是不做距离建模。它**没有**规定本项目使用 δ 或 +5.5 dB。
- Midifan 文章转述某 Dolby 工程解释“+10 再 −4.5 = +5.5”。这是特定渲染行为的二手说明，不是跨渲染器/跨 HRIR 的普遍校准规范。
- 相干平均 IR 按中心 40–80 Hz 幅度归一化后，原生 LFE ×2 在 60 Hz 相对中心 HRIR 约为 +6.0 dB。这是本项目的参考约定；BW4 在 120 Hz 为 −3.01 dB，因此 60/120 Hz 不是同一个数字。

δ 只是不再引入 HRIR 音色；完整 LFE 仍有低通、全通、延迟、归一化、耳机响应，不能叫严格中性。LFE 是否在下混中丢弃取决于下混规范/实现；本项目明确保留它。

## 4. BW4、相位与群延迟

当前数字 BW4 由两个二阶低通级联，Q 为 0.541196100146197 和 1.306562964876377。用实际 48k 双线性变换系数计算：

| Hz | 40 | 60 | 80 | 100 | 120 | 240 |
|---|---:|---:|---:|---:|---:|---:|
| dB | −0.000662 | −0.016929 | −0.166218 | −0.908068 | −3.010300 | −24.101466 |

24 dB/oct 是远离截止、低于 Nyquist 时的渐近斜率，不是任意两频点都精确差 24 dB。120 Hz 低通也不是 120 Hz 以上砖墙阻断。与 LR4 的差在 60/80/100/120 Hz 约 +0.51/+1.40/+2.51/+3.01 dB。

相位延迟 `−φ/ω`、群延迟 `−dφ/dω`、频带最小二乘拟合延迟是不同概念。拟合值不是所有频率恒定的群延迟。

全通 `|A(f)|=1` 只说明幅度不变，不说明群延迟为 0，也不说明可无条件听不出来。默认 `27_95_142`（相干 diffuse、每耳）拟合出的全通为约 5790 Hz / Q 0.143；它主要修正 20–120 Hz 的残差曲率。

### LFE/主路径对齐

LFE 通路（BW4 + 音色 IR）与主通路（7 对 HRIR 的和）在低频群延迟不同。对齐用 20–120 Hz 的等权相干参考：

`Δφ(f) = arg( H_lfe(f) / H_main(f) )`，

对解缠后的 `Δφ` 做直线拟合得到带符号延迟 τ。实现为**主路径一个公共延迟** `Dmain`（保持 L/R ITD 不变）和**LFE 每耳延迟** `Dlfe = Dmain − τ_ear`，再加可选的单位幅度全通。残差用圆周相位误差 `remainder(φ, 2π)` 计算；零传递函数的相位未定义，判为无效。

`27_95_142` 默认结果（48 kHz）：

| 项 | 值 |
|---|---:|
| 拟合主延迟 | 4.29 ms |
| LFE L / R 延迟 | 0.00 / 0.00 ms（扩散场同源，延迟加在主路径） |
| 校正前包裹残差 L / R | 11.73 / 11.73° |
| 全通 | 5790.06 Hz / Q 0.143（校正后平均 5.81°） |

diffuse 音色下 LFE 与主声道使用同一组 HRIR 的相干平均，HRIR 相位精确抵消，拟合只补偿 BW4 低通；因此所有预置的门控都通过。对齐是等权相干参考，不保证任意 FreeSurround 权重或任意原生混音都同相。

### 对齐的独立验证

两个脉冲在同一个 8ch 文件内：LFE 在样本 0，七个主声道在样本 24000。两条路径的响应在同一录音内，因此录音起始相位不影响差值。

| 配置（4096 FFT 定稿版） | 主响应峰 − LFE 响应峰 − 48000 |
|---|---:|
| 对齐关闭 | −201 样本（约 −4.19 ms） |
| 对齐开启 | −9 样本（约 −0.19 ms） |

测试把 LFE 脉冲与七路等权主声道脉冲相隔一秒写在同一个 8ch 文件内，并以持续的极低电平中置信号固定 auto 插件的多声道旁路状态，因此不依赖跨录音绝对时间。峰值不是带限相位拟合的优化目标，但仍从约 4.19 ms 改善到 0.19 ms。

更直接的同录音频域检验：分别截取两个一秒响应窗，在 20–120 Hz（10 Hz 步进）计算 `arg(H_lfe/H_main)`。关闭对齐时左右耳圆周 RMS 均为 **108.64°**；启用主路径 4.29 ms 延迟及 5790.06 Hz/Q0.143 全通后，左右耳均为 **5.81°**，与建图分析预测逐值一致（20–120 Hz 残差约 +3.2/+4.6/+5.8/+6.6/+6.8/+6.3/+4.8/+2.1/−1.8/−6.3/−10.3°）。这证明延迟和全通实际进入了 4096 FFT 定稿图，而不只是分析文本正确。历史 60 Hz 相干和检验还得到分路预测与完整输出一致到 0.2%。

## 5. 低频增强：mono 主声道和的 LFE send（已回滚搁架）

balanced/impact 已回滚为 **mono 主声道和的 LFE send**（−6 dB / 0 dB），不再是搁架：

- send 只存在于 auto 插件的**上混分支**；原生多声道旁路分支不加 send，原生 LFE ×2。
- send 经 120 Hz BW4、七对 HRIR 相干平均的扩散 IR、每耳延迟/全通对齐渲染。
- **30°/15° 相位门控**：校正后残差 >30° 完全禁用 send（实测 AtmosRenderer-Far 249°、dtshx 143° 被禁用）；impact 的 0 dB 要求 ≤15°，否则退回 −6 dB。门控值在建图时固定，运行时模式切换不得超过。
- 旧版 `1 + boost·|P|²` 双耳搁架（1025-tap 线性相位 FIR）与 `binaural_bass` LADSPA label 已整体删除。历史上搁架的数学性质（H=|P|²≥0 非负、零相对相位、DC 增益精确 10^(dB/20)、60 Hz balanced 实测 +3.00 dB）仍然成立，只是不再是产品路径。

## 6. 参考电平不等于节目响度

旧估计 `H_C + .5(H_FL+H_FR)` 再求平方，只代表一个人为的相干输入。反例：C=1、FL=FR=−1 时该和为 0，但独立声道功率完全没有减少。

现实现使用七路互不相关、等功率粉红噪声参考：

`E = [∫ A²(f) (Σ_e,i |H_ei(f)|² /14) d(log f)] / [∫ A²(f) d(log f)]`。

240 个 log 频率中点覆盖 20 Hz 至 min(20 kHz, Nyquist)，A 计权在 1 kHz 精确归一化。对应粉红噪声 PSD~1/f；相对声道极性/纯延迟不改变结果，整体幅度×0.5 得到 −6.0206 dB。只调整整体 trim，±8 dB 上限保留。

它是明确模型下的静态参考电平，不是 LUFS。ITU-R BS.1770-5 节目响度使用 K 计权、各声道均方、声道权重以及 400 ms 块门限；未渲染多声道的 LFE 排除不能机械套到已经包含 LFE 的双耳立体声结果。对实际节目要在最终输出上运行适当响度测量，不能仅靠 IR 推断。

## 7. 输出峰值、headroom 与限幅

0.30 = −10.4576 dB，是固定数字余量，不是对所有多声道输入的削波保证。线性 FIR 的保守时域界为：

`||y_e||∞ ≤ Σ_i ||h_ei||₁ ||x_i||∞`。

多个相关输入、IR 增益、impact 的 0 dB send 及电平匹配都可消耗余量。不能从某个单音估计所有内容上界。

限幅器现在检测**重建峰值**，不是只看离散样本：8 相位、48 抽头多相窗 sinc，音频本身不重采样，只有检测器过采样；`delayLen` 最小为检测器延迟+1（25 样本），默认 5 ms=240 样本。低于阈值且无历史增益时为单位增益+纯延迟；阈值 −1.5 dBFS、release 100 ms。

独立验证用 32 相位、128 抽头 Blackman 窗 sinc 对限幅器输出重新插值：

| 输入 | 输出样本峰 | 独立重建峰 |
|---|---:|---:|
| 12 kHz 相位偏移正弦（1.2 幅度） | 0.594 | 0.756 |
| 23 kHz 近 Nyquist 正弦（1.2） | 0.841 | 0.841 |
| 200 Hz 方波（±1.2） | 0.659 | 0.839 |

三者都在 −1.5 dBFS（0.841）附近或以下。12 kHz 的情况因检测器估计偏保守而多衰减约 0.9 dB；这对安全限幅是可接受的，但说明它仍不是 ITU-R BS.1770 附录 2 意义上的认证 true-peak 表。前瞻/联动限幅在大峰前会衰减同窗口中的较小样本，release 还会继续衰减；“每个低于阈值的样本都透明”不成立。即便重建峰受控，也不能在不知道系统音量/耳机灵敏度/暴露时间时保证听力安全。

## 8. 延迟、启动门控、采样率

- 4096 点 FFT 上混的调度延迟为 6144 样本/48k = **128 ms**；FFT 帧长本身不是 128 ms，后者包含解码器/包装缓冲。4096 是 2026-11-10 深夜回滚定稿：2048 FFT 曾把上混延迟减半到 64 ms，但解码器逐 bin 的幅度/相位差估计变粗，实测 20–120 Hz 的 7.1 通道分配比 4096 少 4–5 dB（120 Hz 以上 ±0.2 dB），低频质感可测地变差，故回滚。
- 主路径还含每预设最多约 20 ms 的 LFE/主对齐延迟；总延迟因此随预设变化。
- `node.latency` 是建议值，官方允许更小或强制的更大 quantum；不是 minimum quantum。
- `audio.rate=48000` 是流边界请求，不能代替实测协商速率和图延迟。HRIR 重采样要验证增益与相位，q14 高质量设置不等于数学逐样本等价。
- 启动门控确实丢弃/衰减信号。它是防突变折中，不是“无损修复”。全局效果图门控可能影响其他同时播放的流。真实源瞬态不能一概认定为爆音。
- 上混开关和 LFE 模式现在是运行时控制，不重建图。只有 HRIR/音色/电平匹配/限幅开关会重建图；新图先接桥，旧图可能还在放 IR 尾巴，而新图需要填满 128 ms 上混延迟。短 IR 下这会留下约 128–150 ms 空洞；没有跨世代逐样本 crossfade。这与稳态音质错误不同。

## 9. 可复现方法与结果

```sh
cmake -B build -G Ninja -DBUILD_TESTING=ON -DBUILD_LADSPA_TEST_HOST=ON
cmake --build build
ctest --test-dir build --output-on-failure
OPENBLAS_NUM_THREADS=1 python3 -I tools/analyze_acoustics.py src/assets/hrir_wav
```

2026-11-10 深夜回滚定稿（FFT 4096 + 相干扩散 send）的结果：

- 普通 Release：CTest **5/5 通过**；`plugin_regression_test` 覆盖任意/变块长、短原生事件、限幅脉冲/联动/阈值/lookahead、独立 12k/23k/方波重建峰、center_image no-op。
- **解码器级 FFT 回滚验证**（离线 harness，同一 20–400 Hz 粉噪直接喂 `freesurround71`，与 2026-10-30 版插件对比）：每通道 RMS 比 0.9989（−0.01 dB，均匀）；mono 主声道和 20–120 Hz 各带差 ≤±0.04 dB（2048 FFT 时代为 −4.0…−5.0 dB）；latency 端口 = 6144。
- 隔离 PipeWire/D-Bus/null sink e2e（27_95、diffuse、per-ear、balanced）：相对 reference 双耳幅度 40/60/80/100/120 Hz = **+3.67/+3.67/+3.62/+3.36/+2.67 dB**（2048 回滚版同法测得；与 §6 历史 f615312 的 +3.57/+3.18/+2.73/+2.07 形状一致，绝对值差异来自测量方法：本轮为单音正交解调，旧数据为多音 RMS）。生成的 `lfe_diffuse_ir.wav` = 218 帧 2ch，能量重心 14.13 样本（旧版 ~14）。
- 对齐 A/B：两脉冲相对峰值从 −160 样本（未对齐）变为 +10 样本（对齐）。
- `pw-top`（1 GHz powersave 状态）：effects playback busy 约 3.2–5.5 ms / 21.3 ms quantum，ERR 0（2048 FFT 时代数据；4096 FFT 上混开销更高但仍在个位数百分比量级）。限幅检测器约 1.8%（1 GHz 单核），满频 <1%。
